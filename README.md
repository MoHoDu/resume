# 모호성 웹 이력서

`index.html`을 브라우저에서 열면 웹 이력서를 볼 수 있습니다. 별도의 프로그램 설치나 빌드 작업은 필요하지 않습니다.

문구를 작성하려면 [CONTENT-EDITING.md](CONTENT-EDITING.md)를 먼저 읽고 `content` 폴더의 해당 구역 파일을 수정하세요. 저장 후 브라우저를 새로고침하면 바뀐 문구가 나타납니다.

배포용 영상은 `assets/*-web.mp4`입니다. `assets/source-*.mp4`는 원본이므로 Git에 올리지 않습니다.

CONTACT의 PDF RESUME 버튼은 새 창에서 8페이지 PDF를 엽니다. 내용이 GitHub에 올라가면 PDF도 자동으로 다시 만듭니다. 페이지 구성과 영상 장면 설정은 [PDF-설정.md](PDF-설정.md)에 정리했습니다.

INTRO의 이미지는 프로젝트 영상의 시작 장면에서 만들었습니다: Octoplug 108초, Doll·Eye Pinball 215초, Rolling Kimbaps 26초, Namer GIF 첫 장면. Doll·Eye의 웹용 영상은 게임 화면만 남도록 원본의 위아래 여백과 주소창을 잘라냈습니다.
